# AGENTS.md

Guidance for coding agents (Codex, Claude Code, Copilot, Cursor, and others) working in this repository. People are welcome to read it too.

## What This Repository Is

A single-file document review page plus three ways to fill it in. Everything runs in the browser or with the Python standard library. There is no server, no build step for users, and nothing is uploaded.

| File | Purpose |
|---|---|
| `template.html` | The review page. The source of truth for layout, styles, and behavior. |
| `builder.html` | The Review Builder. Generated by `src/build.py`. Do not edit by hand. |
| `index.html` | The landing page for the live demo. Generated by `src/build.py`. |
| `src/` | Sources for the generated pages and the build script. |
| `make_review.py` | Builds a finished review from `review.json` and page images. |
| `examples/` | Fictional sample content. |
| `prompts/ai-prompt.md` | The prompt for drafting `review.json` with an AI chat. |

## The Most Common Task: Build A Review From A Document

1. Read the document.
2. Write `review.json` in a new folder under `examples/` (or wherever the user asks), following `examples/lumen-cell/review.json` and the rules in `prompts/ai-prompt.md`.
3. Run `python3 make_review.py <folder>`.
4. Give the user the finished file it prints.

Do not edit `template.html` to make a single review. Content belongs in `review.json` or in the `REVIEW` block only.

## Rules

**Content**
- Copy document wording exactly. Never reword the text a reviewer is approving.
- No redlines or strikethrough. Show the new wording clean; explain changes in the notes.
- Three answers per question: Agree, Agree With Minor Adjustments, Needs A Change.
- Plain language, Title Case headings, no acronyms, no document codes, no ticket numbers, no em dashes.
- Sample content stays fictional. Never commit real company documents or names.

**Design** (Aūno Ambient Glass)
- Inter only. Moving wallpaper behind everything; Aurora is the default.
- Glass panels for supporting content, solid cards for decisions. Depth from light and shadow, not borders or dividers.
- Status is always color plus shape: green check circle, amber triangle, red octagon, hollow grey circle.
- Left align what people read, center what people glance at, share every edge. No dead blank space.
- Text never sits directly on the wallpaper.
- Pill buttons named "Verb: Object". Hold to confirm for destructive actions.

**Behavior**
- Nothing about the reviewer is hard-coded. The approver name comes from the Sign Off form.
- Saved answers stay in the reviewer's browser and expire after `keepAnswersDays`.
- Downloaded and generated reviews are named "Document Name Revision Review.html".
- Keep `template.html` working when opened straight from disk (no fetch, no modules).

## Making Changes To The Pages

1. Edit `template.html`, `src/builder.src.html`, or `src/index.src.html`.
2. Run `python3 src/build.py` so `builder.html` and `index.html` pick up the change.
3. Open the pages in a browser at full width and at 390px wide. Check the console for errors.
4. If behavior or format changed, update `CHANGELOG.md` and the version numbers (`TEMPLATE_VERSION` in `template.html`, `BUILDER_VERSION` in `src/builder.src.html`, `VERSION` in `make_review.py`).
